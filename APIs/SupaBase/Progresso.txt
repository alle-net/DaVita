RESUMO DO PLANO ORIGINAL (Azure)
==============================================================================

- Sistema 100% online composto por API REST + Interface Web
- Hospedagem na Azure (Functions + App Service + SQL Database)
- Substituir planilha Excel por sistema web
- Cadastro e consulta de justificativas por regional
- ~50 registros/dia, até 30 usuários
- Custo zero estimado (tiers gratuitos)

Arquitetura original:
  Azure Functions (API REST Python - 7 endpoints manuais)
  Streamlit (Interface Web)
  Azure SQL Database (Free Tier)

==============================================================================
DECISÃO: MIGRAÇÃO PARA SUPABASE (03/07/2026)
==============================================================================

Após análise, optou-se por substituir Azure SQL + Azure Functions por Supabase.

Motivos:
  ✅ Supabase fornece PostgreSQL + REST API automática + Auth + RLS
  ✅ Elimina necessidade de codificar 7 endpoints manualmente
  ✅ Elimina necessidade de implementar JWT/hash de senha
  ✅ SDK Python nativo (supabase-py) — sem pyodbc problemático
  ✅ Deploy mais simples (apenas Streamlit → 1 serviço)

Arquitetura atual:
  Supabase Cloud (PostgreSQL + REST API automática + RLS)
    ├── Tabelas: fDados, dUsuarios, dRegional, dPendencias, dResponsavel
    ├── RLS (Row Level Security) protege os dados
    └── Autenticação: hash SHA-256 (login manual via Python)
  Streamlit (Interface Web)
    ├── Login (email + senha com hash)
    ├── Novo Registro (formulário com filtro ativo/inativo)
    ├── Consultar com filtros + exportar CSV
    └── Admin (gerenciar usuários)

==============================================================================
PLATAFORMA DE HOSPEDAGEM DA INTERFACE
==============================================================================

Opções consideradas:
  - Streamlit Community Cloud (grátis) → cold start ~30s, 60min CPU/dia
  - Railway (US$ 5/mês) → sem cold start, sem limite CPU
  - Fly.io (grátis - 3 VMs) → sem cold start, sem limite CPU

Decisão: Começar com Streamlit Cloud grátis. Migrar se necessário.

==============================================================================
PERGUNTAS ESCLARECIDAS
==============================================================================

  1. Autenticação: Admin cria contas via Supabase Dashboard.
     Usuário loga com email+senha. Supabase gerencia JWT.
  2. Supabase não é "só banco": fornece DB + API automática + Auth + RLS.
  3. Cold start: app "dorme" após inatividade, ~30s para acordar.
  4. Limite CPU de 60 min/dia do Streamlit: suficiente para ~50 registros/dia
     (estimativa de ~7,5 min de CPU/dia = 12,5% do limite).
