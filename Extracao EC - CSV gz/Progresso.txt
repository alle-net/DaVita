====================================================================================
EXTRACAO DO DADOS EC
====================================================================================

OBJETIVO GERAL:
 
Criar uma rotina que tem como objetivo conectar-se ao banco de dados mysql executar
uma consulta e salva-la em uma pasta do SharePoint em formato CSV compactado (GZip).

1 instale as bibliotecas no seu terminal: pandas, PyMySQL, SQLAlchemy.

2 configure o arquivo Config.json com os dados de conexão: servidor, banco, usuário e pasta de saída.

3 execute o script: python extracao.py

4 o arquivo sera salvo como EC-YYYYMMDD-HHMM.csv.gz na pasta configurada.
