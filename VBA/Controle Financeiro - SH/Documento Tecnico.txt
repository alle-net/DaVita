Versão: 1.0 | Data: 27/05/2026 | Plataforma: Excel Desktop (Windows) + VBA

1. OBJETIVO DO APLICATIVO
Sistema desktop para cadastro, edição e exclusão de dados tabulares, com:
- Autenticação por email e senha
- Isolamento rigoroso de registros por usuário logado
- Interação com dados EXCLUSIVAMENTE via formulário
- Compatibilidade total com Power Query para extração/transformação
- Arquitetura escalável Fato x Dimensão

2. MODELO DE DADOS
[tblRegistros] - Tabela Fato
Colunas: ID | Data | Descricao | Valor | Status | ID_Usuario
Função: Armazena registros operacionais

[tblUsuarios] - Tabela Dimensão
Colunas: ID | Email | Status
Função: Gerencia identidade e estado de acesso

[tblStatus] - Tabela Dimensão (Exemplo)
Colunas: Codigo | Descricao
Função: Alimenta ComboBox e valida regras de negócio

REGRA DE OURO: A tabela tblUsuarios NAO contem colunas de senha.
Credenciais sao armazenadas exclusivamente no codigo VBA.

3. FLUXO DE AUTENTICAÇÃO
1. Abertura do arquivo -> frmLogin exibe automaticamente (modal)
2. Validacao em cadeia:
   - Email existe em tblUsuarios
   - Status = "Ativo"
   - SHA256(SenhaDigitada + Salt) == HashArmazenadoNoVBA
3. Se valido:
   - Variavel publica UsuarioAtual recebe o ID do usuario
   - Aba Dados torna-se xlSheetVisible
   - AutoFilter aplicado automaticamente na coluna ID_Usuario
   - frmPrincipal abre em modo vbModeless
4. Se invalido: bloqueia acesso, limpa senha, mantem formulario aberto

4. INTERFACE E FUNCIONALIDADES DO FORMULARIO
- frmPrincipal: Nao pode ser fechado pelo X (QueryClose bloqueado). Permite minimizacao/maximizacao.
- Grid (ListBox): Exibe APENAS registros do UsuarioAtual. Paginacao fixa: 25 registros por pagina.
- Navegacao: Botoes Anterior / Proximo + label "Pagina X de Y (N registros)"
- Campos: txtID, txtData, txtDescricao, txtValor, cboStatus (populado por tabela dimensao)
- Acoes: Adicionar, Editar, Excluir, Limpar
- Interacao: Usuario NAO edita a planilha diretamente. Todos os CRUDs passam pelo VBA.

5. CONTROLE DE ACESSO E SEGURANCA
- Planilha oculta: xlSheetHidden (mantem compatibilidade com Power Query)
- Protecao: UserInterfaceOnly:=True, AllowFiltering:=True, bloqueio total de insercao/exclusao manual
- Menus desativados: CommandBars("Cell"), Row, Column, List Range Popup desabilitados no Workbook_Open
- CRUD seguro: Usa ID como chave unica via .Find(). Nunca depende de indice de linha bruto
- Senhas: Hash SHA-256 + Salt, armazenadas em Const no modulo VBA
- Sessao: Public UsuarioAtual As String. Reseta ao fechar o Excel

6. COMPATIBILIDADE COM POWER QUERY
- xlSheetHidden NAO interfere no Power Query
- Protecao UserInterfaceOnly:=True permite leitura normal de tblRegistros
- REGRA PARA CONEXOES PQ: usar Excel.CurrentWorkbook(){[Name="tblRegistros"]}[Content]
- Credenciais, logica de login e validacoes NUNCA sao carregadas no modelo de dados

7. STACK E DETALHES TECNICOS (VBA)
- Tabelas dinamicas: ListObject + ListRows
- Paginacao: Array em memoria AllData(), calculo de StartIdx/EndIdx por PAGE_SIZE = 25
- Hashing: System.Security.Cryptography.SHA256Managed + ADODB.Stream (UTF-8)
- Navegacao: Variaveis CurrentPage, TotalPages, TotalRecords
- Eventos: Workbook_Open, Workbook_BeforeClose, UserForm_QueryClose
- Performance: Leitura unica ao abrir form. Atualizacoes em lote via CarregarDadosUsuario

8. DIRETRIZES PARA AGENTES DE IA
Ao gerar, revisar ou estender codigo, RESPEITE OBRIGATORIAMENTE:
1. Nunca armazenar ou expor senhas na planilha ou em intervalos
2. Manter CRUD via ListObject usando ID como chave, nunca ListIndex bruto
3. Preservar paginacao em memoria (25/page) e filtro por UsuarioAtual
4. Garantir compatibilidade com Power Query em qualquer alteracao
5. Manter frmPrincipal nao fechavel e planilha protegida com UserInterfaceOnly:=True
6. Separar claramente: Dados Fato x Dimensoes x Credenciais (constantes VBA)
