INSTRUCOES DE IMPORTACAO (ATUALIZADO)
========================================

Arquivo: Controle Financeiro SH.xlsm

PASSO 1 - Importar modAutenticacao
- Abra o Excel > Controle Financeiro SH.xlsm
- Alt+F11 (Editor VBA)
- File > Import File > modAutenticacao.bas

PASSO 2 - Importar criarFormulario
- File > Import File > criarFormulario.bas

PASSO 3 - Executar a macro para criar o formulario
- Ainda no Editor VBA, aperte Ctrl+G (Janela Imediata)
- Digite: CriarFrmLogin
- Pressione Enter
- Deve aparecer "Formulario frmLogin criado com sucesso!"

PASSO 4 - Adicionar codigo no ThisWorkbook
- Project Explorer > duplo clique em "ThisWorkbook"
- Cole o codigo abaixo SUBSTITUINDO tudo:

---------- COPIAR ----------
Option Explicit

Private Sub Workbook_Open()
    modAutenticacao.ResetarSessao
    frmLogin.Show vbModal
End Sub

Private Sub Workbook_BeforeClose(Cancel As Boolean)
    On Error Resume Next
    Sheets("Dados").AutoFilterMode = False
    modAutenticacao.ResetarSessao
End Sub
---------- PARAR ----------

PASSO 5 - Salvar e testar
- Ctrl+S (salvar)
- Feche e reabra o arquivo
- Selecione o email e digite: 102030

OBS: Se a macro do Passo 3 falhar com "Project locked", feche e reabra o arquivo e tente novamente.
