=== COMO ADICIONAR UM NOVO MODULO ===
1. Criar arquivo .ts em src/components/ com funcão renderizadora:
     export function renderMeuModulo(container, { onVoltar }): () => void
2. Criar .css correspondente (opcional)
3. Importar em src/registry/registerModules.ts
4. Registrar:
     ModuleRegistry.registrar({
       chave: 'MeuModulo',
       nome: 'Meu Modulo',
       renderizar: renderMeuModulo,
     });
5. Adicionar permissao na planilha dPermissoes para o usuario

PASSOS PARA INSTALAR NO EXCEL ONLINE:
  1. Navegar ate a pasta no SharePoint
  2. Criar pasta FormLogin com subpasta assets/ (se nao existir)
  3. Fazer upload de todos os arquivos acima
  4. Abrir Excel Online (workbook qualquer)
  5. Clicar em: Pagina Inicial (Home) > Suplementos (Add-ins)
  6. No painel direito, clicar em "Mais Configuracoes" ou "Avançado"
  7. Na janela "Suplementos do Office", clicar "Carregar Meu Suplemento"
  8. Navegar ate o manifest.xml no SharePoint e selecionar
  9. Clicar em "Upload" (Carregar)
  10. O botao "Abrir Login" aparecera na faixa de opcoes (ribbon)

OBSERVACOES:
  - O sideload via "Carregar Meu Suplemento" e por usuario/navegador
    (armazena na cache do navegador)
  - Para deploy corporativo (todos usuarios), usar Catalogo de Aplicativos
    do SharePoint (App Catalog) ou Centralized Deployment no admin M365
  - O manifest-localhost.xml pode ser usado para testes locais com
    "npm start"

=== CONTRATO DAS FUNCOES RENDER ===
Toda funcao de modulo deve seguir:
  (container: HTMLElement, props: ModuloProps) => () => void
Onde ModuloProps = { onVoltar: () => void }
E o retorno e uma funcao de cleanup para remover event listeners.
