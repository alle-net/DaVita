=== ARQUITETURA DEFINIDA ===
- Tecnologia: Office Add-in (Task Pane) + React 18 + TypeScript
- Autenticacao: Stateless via planilha dUsuarios (mesmo workbook ou ListaDeUsuarios.xlsx)
- Permissoes: Abas dPermissoes + dModulos
- Sessao: React Context (AuthContext)
- Login reutilizavel para futuros projetos

=== ESTRUTURA DO PROJETO ===
FormLogin/
  manifest.xml              - Manifesto do Add-in
  package.json              - Dependencias (React, Webpack, TS, Office.js)
  tsconfig.json             - Config TypeScript
  webpack.config.js         - Bundler
  src/
    config.json             - Config (URL planilha, nomes abas)
    config/ConfigService.ts - Leitor do config.json
    auth/
      AuthContext.tsx        - Context React (userId, email, permissoes)
      LoginScreen.tsx       - Tela de login
      LoginScreen.css       - Estilos do login
      LoginService.ts       - Validacao de credenciais via Excel
      PermissaoService.ts   - Busca permissoes + modulos
    components/
      MainScreen.tsx        - Tela principal apos login
      MainScreen.css        - Estilos da main
    registry/
      ModuleRegistry.ts     - Registro de modulos (escalavel)
    taskpane/
      taskpane.html         - HTML base
      taskpane.tsx          - Entry point React
      taskpane.css          - Estilos globais
      App.tsx               - Componente raiz (login vs main)
    commands/
      commands.ts           - Comandos Office
  assets/
    icon-16.png, icon-32.png, icon-80.png
